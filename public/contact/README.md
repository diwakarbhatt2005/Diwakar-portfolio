# Contact background

- `sky.mp4` — looping, muted background video for the contact section (1920×1080, keep it short and under ~2 MB).
- `sky-poster.webp` — a still frame of the same video. It shows instantly before the video loads, and is all that's shown when the visitor prefers reduced motion or has Data Saver on.

Replace both with the same names to change the background.
